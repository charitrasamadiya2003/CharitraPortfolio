# Charitra Portfolio

This is my personal portfolio website built using **React.js and Vite**.  
It showcases my skills, projects, experience, and an updated resume in a clean and responsive design.

## 🚀 Tech Stack
- React.js
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- Bootstrap
- Git & GitHub

## ✨ Features
- Modern and responsive UI
- Updated profile section
- Skills and tools showcase
- Downloadable resume
- Deployed and live on the web

## 🌐 Live Demo
👉 https://charitra-portfolio.vercel.app/

## 📂 Repository Purpose
This repository contains the **frontend code only** for my portfolio.  
Backend code has been intentionally excluded to keep the repository clean and focused.
