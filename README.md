Welcome to my Full-Stack Developer Portfolio

This is a fully responsive and dynamic personal portfolio website built using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The portfolio showcases my projects, skills, resume, and includes a fully functional contact form.

When a visitor sends a message through the contact form, the data is handled by the backend and stored/sent appropriately, demonstrating real-world full-stack integration.

🔧 Tech Stack:
Frontend: React.js, HTML5, CSS3, Bootstrap, JavaScript

Backend: Node.js, Express.js

Database: MongoDB

Deployment: Frontend on Vercel | Backend on Render


📌 Features:
Modern and clean UI/UX

Mobile-responsive design

Dynamic project showcase

Downloadable resume section

Contact form with backend integration

Deployed and live on the internet
